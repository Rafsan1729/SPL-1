# Project Scope

## Project Title

**Interactive Algorithm Analysis and Visualization Tool**

## Purpose

This project aims to make selected algorithms easier to learn by showing their operations step by step. It connects algorithm concepts with C implementations and presents information about execution time and space complexity.

## Users

The intended users are students and beginners who want to learn algorithms and data structures from the basics.

## Included in the Project

The planned application is written in C and covers the following algorithms:

| Category  | Algorithms                             |
| --------- | -------------------------------------- |
| Sorting   | Pancake Sort, Cycle Sort               |
| Searching | Skip List Search, Interpolation Search |

The application is intended to let a user:

1. Enter data.
2. Select a sorting or searching task.
3. Choose one of the algorithms included in the project.
4. View the algorithm's steps and final result.
5. Review execution-time and space-complexity information, including graphs.

## Learning Focus

The step-by-step output is intended to help users follow how an algorithm processes input. Complexity information and graphs are intended to help users connect the demonstrated process with algorithm analysis.
