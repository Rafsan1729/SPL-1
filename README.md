# Interactive Algorithm Analysis and Visualization Tool

## Project Overview

The **Interactive Algorithm Analysis and Visualization Tool** is a C-based project for helping students and beginners understand how selected sorting and searching algorithms work. Users can enter data, choose an algorithm, follow its steps, and review its result and complexity information.

## Algorithms in Scope

### Sorting

- Pancake Sort
- Cycle Sort

### Searching

- Skip List Search
- Interpolation Search

## Planned Features

- A simple menu for choosing a sorting or searching task
- User-entered data for algorithm demonstrations
- Step-by-step output to make each algorithm's process easier to follow
- Display of results
- Execution-time and space-complexity information, including conceptual graphs

## Intended Users

Students and beginners who are learning algorithms and data structures.

## Technology

- Programming language: C
- Repository and version control: GitHub

## Project Status

This repository is for the development of the project. The features described above represent the intended scope; they should not be taken as a claim that every feature is already implemented.
